# AID-X Day

AID-X Day 행사 안내 페이지예요. QR로 폰에서 여는 걸 기준으로 만들었어요.

- 페이지: https://rohminji.github.io/2026-AID-X-Day/
- 내용 수정: `index.html` 스크립트 상단의 `EVENT` 블록만 고치면 돼요.
  `[대괄호]` 값은 자리표시자라서 페이지에 노란색으로 보여요.
- 카운트다운 기준: `startISO` / `endISO` (한국 시간 `+09:00`)
